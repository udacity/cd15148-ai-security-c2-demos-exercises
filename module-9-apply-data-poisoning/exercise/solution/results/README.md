# Results Directory

The solution notebook writes metrics CSV files, plots, and executed notebooks here.

`assessment_report_baseline.md` is the completed reference answer for the written
deliverable. Learners copy `../docs/assessment_report_template.md` to
`assessment_report.md` and fill that in; the `_baseline` copy is never overwritten
by a run.

Generated result files are ignored by git. Committed reference files use the
`_baseline` suffix.
